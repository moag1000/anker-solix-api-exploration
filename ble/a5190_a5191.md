# A5190 and A5191 (EV Charger V1) BLE

The V1 Smart EV Charger (product codes A5190 and A5191). Both codes share one UI module, one command file and one BLE connect plumbing, so they have one page. The app has no per-product BLE controller for them: there is no `A5190DeviceController`, and the factory gives both the generic fallback. The device commands are named property writes handed to the IoT kit, not ZX opcodes. This page owns the BLE-specific facts (profile, connect plumbing, which kit call each method uses); the property names and values are owned by [../devices/ev_charger.md](../devices/ev_charger.md), the kit channels by [../reference/iot_kit_channels.md](../reference/iot_kit_channels.md). The frame, fragmentation and encryption are on [protocol.md](protocol.md), the negotiation on [handshake.md](handshake.md).

Evidence is the asm of 3.24.3 (`file.dart @0xADDR`; `ev_charger/` files are relative to `ev_charger/src/ev_charger/`, others to the asm root or `charging/` as named). Number conventions: a count taken from `AllocateArray` is stated as elements (raw value divided by 2, Smi rule).

#### Direction

app to kit (app side: the Dart layer hands the map to the native IoT kit). Reads come back as kit results. Which transport (BLE, MQTT or cloud) the kit uses for a given call is below the Dart layer and is not shown by the asm; the maps built by these methods contain no `bleMac` key (the A1782 module's actions do, see [a176x_a178x.md](a176x_a178x.md)).

#### Packet framing

none on the Dart side; the kit frames the data. For the ZX frame of the opcode-based products see [protocol.md](protocol.md#frame-on-ble).

#### Handshake prerequisite

Not visible in the Dart code of these methods; the BLE connect plumbing is in [BLE profile](#ble-profile) and the negotiation in [handshake.md](handshake.md).

#### TLV tags

Owned by [../devices/ev_charger.md](../devices/ev_charger.md#mqttble-command--tlv-tag--apk-field-name-mapping): property names, value tables and the candidate tag table. This page adds the method-to-kit-call map above.
