# A17X8 MQTT commands

Smart Plug (A17X8): the 0405 status message, the timer status (CountDownInfo), the schedule readback (TimingInfo) and the SET opcodes 007a, 007c, 007e plus the request opcodes the 3.24.3 app builds. The envelope, topics, frame layout and data type codes are owned by [envelope.md](envelope.md) and are not repeated here. A17X7 (smart meter) is a different product: [a17x7.md](a17x7.md).

Evidence rows are written `audit row N` and refer to [../docs/audit/BLE_COMMAND_MAP.md](../docs/audit/BLE_COMMAND_MAP.md); `file.dart @0xADDR` is 3.24.3 asm. Opcodes are the hex strings of the Dart source (pool lists `[0, 0x7a]` are the same two bytes, never halved); tag keys are halved Smi immediates (raw 324 is tag `a2`), per the Smi rule in [../METHODOLOGY.md](../METHODOLOGY.md#smi-rule-reading-numbers-from-blutter-output). Names are upstream's (`api/mqttmap.py`, `api/mqttcmdmap.py`); a name of ours is marked `(no upstream name)`. Controller file: `charging/ble/device/A17X8/a17x8_device_controller.dart`; parsers: `a17x8_device_commands.dart`. The audit's device-tested prose (row 1) covers 007a, 007c and 007e; see each command's last section.
