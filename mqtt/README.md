# MQTT

This directory holds one decoder page per product number (`<pn>.md`, lowercase PN) that owns the MQTT field maps for that product, plus `envelope.md` for the JSON envelope, topics, compression and command types shared by all products.

Not here: endpoint payloads ([../api/README.md](../api/README.md)), BLE opcodes and TLV ([../ble/README.md](../ble/README.md)); owner map in [../docs/STRUCTURE.md](../docs/STRUCTURE.md).
