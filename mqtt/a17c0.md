# A17C0 MQTT commands (Solarbank E1600)

Solarbank E1600 (A17C0, Gen 1): the 0405 status message and the setters of the A17C0 controller. The envelope, topics, frame layout and data type codes are owned by [envelope.md](envelope.md); the shared Solarbank 2 setters are on [a17c1.md](a17c1.md).

Evidence rows are written `audit row N` and refer to [../docs/audit/BLE_COMMAND_MAP.md](../docs/audit/BLE_COMMAND_MAP.md); `file.dart @0xADDR` is 3.24.3 asm. Opcodes are the hex strings of the Dart source (pool lists are the same bytes, never halved); tag keys are halved Smi immediates (per the Smi rule in [../METHODOLOGY.md](../METHODOLOGY.md#smi-rule-reading-numbers-from-blutter-output)); store offsets are Blutter byte offsets. Names are upstream's (`api/mqttmap.py`, `api/mqttcmdmap.py`); a name of ours is marked `(no upstream name)`.

## Commands

### 0405 status message (param_info)

#### Purpose
Periodic status of a Solarbank E1600 (A17C0, Gen 1): SOC, PV and output power, energy counters, cut-off settings, inverter data and the sub-battery link.

#### Upstream name
`"0405"` of A17C0, topic `param_info` (`mqttmap.py` lines 4927-4957), upstream-confirmed. The old doc counted 23 upstream-named tags and 11 new ones, and labelled the new ones from other families.

#### Command code
`"0405"`, parsed by `A17C0DeviceCommands.parseDeviceAllInfo` @0x3b5295c (size 0x2664) and `parseWorkInfo` @0x3b50074 (size 0x21a4) in `charging/ble/device/A17C0/a17C0_device_commands.dart`; the file also has `parseDeviceMessage` @0x3b4ffa4, `_cloudA17Y0InfoSync` @0x3b52218 and `parseErrorInfo` @0x3b5288c (function start and size from the asm header, not in the audit). Asm-traced for the parsers; upstream-confirmed for the message id.

#### Direction

#### Topic pattern

### Setters 0050, 005e, 0067, 0068, 0071

#### Purpose
Sets the temperature unit, the discharge schedule, the SOC cut-offs, the micro-inverter model and the electricity price of a Solarbank E1600.

#### Upstream name
`CMD_TEMP_UNIT`, `CMD_SB_POWER_CUTOFF` and `CMD_SB_INVERTER_TYPE` for A17C0 (`mqttmap.py` lines 4922, 4925, 4926; definitions in `mqttcmdmap.py` lines 250, 603, 639), upstream-confirmed; also bound upstream for A17C0 are `"0040"` status request (line 4921), `"0056"` `CMD_SB_STATUS_CHECK` (line 4923) and `"0057"` realtime trigger (line 4924). Details of the upstream commands: [upstream_commands.md](upstream_commands.md).

#### Command code
Hex strings are the pool lists of `charging/ble/device/A17C0/a17C0_device_controller.dart` (never halved). Asm-traced for opcodes and tag keys; the setter `setDeviceUpdateEnergy` @0x4081890 (a 0x57 builder, audit row 229) is documented on [a17c1_status.md](a17c1_status.md#0057-realtime-trigger).

#### Direction
app→device. Tag: asm-traced.

#### Topic pattern
[envelope.md](envelope.md#topics): `cmd/anker_power/A17C0/<sn>/req`.

#### Payload fields
Tag keys are halved Smi immediates (324 is `a2`; 346 is `ad`).
