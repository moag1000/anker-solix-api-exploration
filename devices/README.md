# Devices

This directory holds one product page per product number (`<pn>.md`): a short summary, links to the API, MQTT and BLE owner pages, and the device-tested status. The legacy pages (`ev_charger.md`, `home_power_panel.md`, `smart_plug.md`, `solarbank.md`, `x1_hes_e10.md`) stay until the migration map marks them done.

Not here: payloads, field maps or opcodes; owners are listed in [../docs/STRUCTURE.md](../docs/STRUCTURE.md).
